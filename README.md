# LAB A3 - Thiết kế giao diện với XML Layout & tài nguyên

**Họ và tên:** Trịnh Phạm Xuân Nghi  
**MSSV:** 231A010740  
**Môn:** Lập trình trên các thiết bị di động  

## Nội dung thực hiện

- Thiết kế màn hình đăng nhập bằng LinearLayout
- Dựng lại màn hình đăng nhập bằng ConstraintLayout
- Tạo giao diện riêng cho màn hình ngang bằng layout-land
- Sử dụng ScrollView cho nội dung màn hình
- Tách tài nguyên strings, colors, dimens và drawable
- Hiển thị thông tin sinh viên bằng thẻ hồ sơ và sử dụng include
- Xử lý nút ĐĂNG NHẬP hiển thị Snackbar

## Bài nâng cao

### NC1 - Dark Mode
Tạo `values-night/colors.xml` để ứng dụng tự sử dụng bộ màu phù hợp khi thiết bị chuyển sang chế độ tối

### NC2 - Giao diện Tablet
Tạo `layout-sw600dp/activity_main.xml` với bố cục 2 cột dành cho màn hình tablet và tái sử dụng thẻ hồ sơ bằng `include`

## Môi trường thực hiện

- Android Studio Quail 3 | 2026.1.3
- Java + XML
- Minimum SDK: API 24
- Thiết bị chạy thử: Small Phone
- Android 7 (API 24)
